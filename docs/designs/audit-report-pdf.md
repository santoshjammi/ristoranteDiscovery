# Design: Audit Report PDF Generation (P2)

## Purpose
Generate downloadable PDF audit reports for restaurant visibility analysis.

## Backend Service
- New file: `backend/src/services/audit-pdf.service.ts`
- Uses `pdfkit` (already in dependencies) to generate PDF
- PDF includes: restaurant name, address, overall score, category scores, factor breakdown, recommendations, generated date

## API Endpoint
- `GET /api/audit/:restaurantId/pdf` — returns PDF as downloadable file
- Auth required (authMiddleware)
- Content-Type: `application/pdf`
- Content-Disposition: `attachment; filename="audit-{restaurantId}.pdf"`

## PDF Structure
1. **Header**: Ristorante Discovery logo/title, "Visibility Audit Report", date
2. **Restaurant Info**: name, address, cuisine, price range
3. **Score Summary**: Overall score (large), category scores as bar chart (text-based)
4. **Factor Breakdown**: Table with factor name, score, status (good/warning/critical)
5. **Recommendations**: Top 3-5 actionable recommendations
6. **Footer**: Generated by Ristorante Discovery, page numbers

## Frontend
- Add "Download PDF" button on audit report page
- Button calls `GET /api/audit/:restaurantId/pdf` with auth token
- Opens in new tab or triggers download
